# نظام إدارة فنادق السعفة | As'saafa Hotels Management System

نظام متكامل لإدارة مجموعة فنادق السعفة (فندق السعفة + فندق السعفة الذهبية).
عربي/إنجليزي مع دعم RTL كامل، وثيم مستوحى من ألوان الشعار (أخضر السعف + الذهبي).

## المكوّنات

- **backend/** — Django 5.2 + DRF + JWT (SQLite) — بورت **8020**
- **frontend/** — React 19 + TypeScript + Vite + Ant Design + RTK Query — بورت **5180**

| **ملف العميل (KYC)** | الحجز الأونلاين يُلزم الجنسية + نوع الإثبات (هوية وطنية/إقامة/جواز عادي-دبلوماسي-مهام) + رقمه، مع رفع صورة الإثبات — تُحفظ في ملف كامل للعميل بالمستندات داخل صفحة النزلاء |

| **صفحة رئيسية كاملة** | بانر متحرك (Ken Burns) + اختيار الفندق + قسم تعريفي بإحصائيات + شبكة الخدمات + معرض صور بلايت بوكس |

| **موقع متعدد الصفحات** | موقع تعريفي كامل بهيدر ثابت وفوتر: رئيسية · الفنادق · تفاصيل كل فندق · الخدمات · المعرض · تواصل معنا · الحجز — بمحتوى الموقع الرسمي assaafahotels.com |

## التشغيل السريع

```bash
./start.sh          # يشغّل الباك والفرونت معاً
```

أو يدوياً:

```bash
# Backend
cd backend && source venv/bin/activate
python manage.py runserver 8020

# Frontend
cd frontend && npm run dev
```

ثم افتح:
- **لوحة الإدارة:** http://localhost:5180
- **موقع الحجز للنزلاء:** http://localhost:5180/book (بدون تسجيل دخول)

حجوزات الموقع تصل للوحة الإدارة بمصدر «الموقع الإلكتروني» وحالة «بانتظار التأكيد».

### صفحات موقع النزلاء
- `/site` الرئيسية · `/site/hotels` الفنادق · `/site/hotel/sf` و`/site/hotel/sfg` تفاصيل الفندق
- `/site/services` الخدمات · `/site/gallery` المعرض · `/site/contact` تواصل معنا
- `/book` الحجز (فردي/مجموعات)

## بيانات الدخول

- **المدير العام:** `admin` / `admin123`
- **استقبال السعفة:** `reception_sf` / `123456`
- **استقبال السعفة الذهبية:** `reception_sfg` / `123456`

## إعادة تهيئة البيانات التجريبية

```bash
cd backend && source venv/bin/activate
python manage.py seed        # الأساس: فندقين + غرف + نزلاء
python manage.py seed_extra  # أسعار موسمية + خدمات + كوبونات + تدبير + تاريخ 30 يوم
```

## كوبونات تجريبية

- `WELCOME10` — خصم 10%
- `SUMMER50` — خصم 50 ر.س
